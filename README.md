# Super Mario Jump 

Jogo 2D desenvolvido em JavaScript inspirado em jogos de plataforma clássicos.

## Funcionalidades
- Sistema de pulo com física básica
- Obstáculos dinâmicos
- Detecção de colisão
- Loop de jogo em tempo real

## Tecnologias
- JavaScript
- HTML
- CSS

## Objetivo
Praticar conceitos de desenvolvimento de jogos, incluindo lógica de movimento, colisão e interação.
